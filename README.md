# 🍬 Candy Crush Game

An interactive, responsive Candy Crush web game built with pure **HTML5, CSS3, and Vanilla JavaScript**.

![Candy Crush Gameplay Preview](https://c.tenor.com/x8v1oNUOmg4AAAAd/tenor.gif)

---

## 🎮 Game Features
- **Two Game Modes**:
  - **Endless Mode**: Play at your own pace without time limits.
  - **Timed Mode**: Score as high as possible before the countdown timer runs out!
- **Dynamic Board (8x8 Grid)**:
  - 6 vibrant candy types (Red, Blue, Green, Yellow, Orange, Purple).
  - Gravity-based falling physics when candies are crushed.
- **Interactive Drag & Drop**:
  - Intuitive desktop mouse drag-and-drop controls.
  - Automatic validity checking for valid 3-in-a-row or 4-in-a-row combinations.
- **Live Scoreboard & Timer**:
  - Instant score calculation and visual scoreboard display.

---

## 🚀 How to Play
1. **Clone or Download** the repository:
   ```bash
   git clone https://github.com/praj29819-code/candy-crush.git
   ```
2. Open `index.html` in any web browser:
   - Double click `index.html`, OR
   - Run a quick local server:
     ```bash
     python -m http.server 3000
     ```
     And open [http://localhost:3000](http://localhost:3000) in your browser.
3. Select your mode: **Endless** or **Timed**.
4. Drag and swap adjacent candies to match 3 or more of the same color!
